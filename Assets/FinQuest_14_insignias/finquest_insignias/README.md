# FinQuest · Insignias de retos

14 insignias originales. Cada una incluye SVG editable y PNG transparente de 256 × 256 px. Los nombres de archivo coinciden con el campo id de manifest.json. La misión mensual de diciembre no tiene XP fijado para permitir configurarlo en la app.

Los retos de no gastar excluyen gastos esenciales. La silueta de puño está adaptada del icono HandFist de Lucide (licencia ISC).
